FFXIV Disciples of the Hand · EXP planner

Collectable Leveling Ledger

Enter each crafting job's current level and current EXP in that level. The ledger takes it from there — for every job, it works out exactly how many of each Rarefied collectable to craft and turn in to level 100 (or an earlier target level, if you set one).

Below level 71, class quests (1-15) and Cosmic Exploration (15-70) are how you level. Cosmic Exploration needs Endwalker's MSQ finished first; if you haven't, Ishgardian Restoration covers 20-80 stretch instead. From 71 onward, Cosmic Exploration is still an option, but this tool models the collectable route. It assumes 100% quality (+300% bonus EXP) and no external buffs like rested EXP or food.

Each item name links straight to its FFXIV Teamcraft item page. "Copy Teamcraft import link" copies a Garland Tools-format list link with every item and its exact quantity already encoded -- paste it into Teamcraft under Lists → the import icon → "paste your link to the external list" to build a list.
