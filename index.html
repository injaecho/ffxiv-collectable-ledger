Collectable Leveling Ledger

Enter each crafting job's current level and current EXP in that level. The ledger takes it from there — for every job, it works out exactly how many of each Rarefied collectable to craft and turn in to level 100 (or an earlier target level, if you set one).

Below level 71, class quests (1-15) and Cosmic Exploration (15-70) are how you level. Cosmic Exploration needs Endwalker's MSQ finished first; if you haven't, Ishgardian Restoration covers 20-80 stretch instead. From 71 onward, Cosmic Exploration is still an option, but this tool models the collectable route. It assumes 100% quality (+300% bonus EXP) and no external buffs like rested EXP or food. "Craft my own components" (experimental) recursively prices out that collectable's full ingredient tree at 0% quality, unlocking in 71-74 / 75-80 / 81-84 / 85-90 / 91-94 / 95-100 brackets as each bracket's intermediate recipes become available -- below a bracket's floor, components are bought instead, same as with the toggle off. All 8 jobs are simulated through those brackets together, so EXP a job earns for other jobs while crafting its own components actually carries over into their level progress at the start of the next bracket -- priced using each job's level at the start of the current bracket, not a full turn-in-by-turn-in simulation of every job leveling in lockstep. The one exception is the final 95-100 bracket, whose cross-job EXP has no further bracket to carry into and shows as an informational note instead.

Each item name links straight to its FFXIV TeamCraft item page. "Copy TeamCraft import link" copies a Garland Tools-format list link with every item and its exact quantity already encoded -- paste it into TeamCraft under Lists → the import icon → "paste your link to the external list" to build a list.
